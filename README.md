# Gym Management System

A full-stack Gym Management System for managing members, workouts, and daily operations in one place.

## Features
- Member management
- Workout and training plan tracking
- Admin dashboard
- Clean, responsive UI
- Backend API integration
- Docker support

## Tech Stack
- **Frontend:** Vite, React
- **Backend:** Node.js / Express
- **Database:** MongoDB
- **Deployment:** Docker, Docker Compose

## Project Structure
- `src/` — Frontend source code
- `gym-backend/` — Server-side API
- `gym-management/` — Main app module
- `public/` — Static assets
